# 🎬 CineVault

CineVault is a modern movie and TV discovery platform where users can discover movies and TV shows, search for titles, manage favorites, and build their personal watchlist.

## 🚀 Features

- 🔐 User authentication
- 🎬 Movie discovery
- 📺 TV show discovery
- 🔍 Search movies and TV shows
- ❤️ Add movies and shows to favorites
- ⭐ View ratings and movie information
- 📋 Personal watchlist
- 🎞️ Movie and TV show details
- 📱 Responsive user interface

## 🛠️ Tech Stack

- React
- React Router
- Redux Toolkit
- React Hook Form
- Tailwind CSS
- TanStack Query
- Axios
- TMDB API
